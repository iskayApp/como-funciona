# ¿Cómo accedo a documentos sujetos a confidencialidad o solicitud?

<div class="test-note" role="note"><strong>Pendiente de revisión editorial.</strong> Esta ficha se publica para revisión y puede recibir ajustes.</div>

## Respuesta breve

No todos los documentos de una iniciativa tienen el mismo nivel de acceso. Algunos pueden consultarse directamente; otros requieren aceptar un Acuerdo de Confidencialidad o solicitar autorización.

Ambas condiciones son diferentes y pueden aplicarse a la información de una misma campaña.

## ¿Cuándo debes aceptar un Acuerdo de Confidencialidad?

El promotor puede activar esta opción para proteger información de la iniciativa. En ese caso, antes de consultar el contenido sujeto a reserva debes aceptar el acuerdo correspondiente.

La reserva puede afectar a la Descripción completa, la pestaña Documentación, los archivos compartidos con colaboradores y sus informes.

Aceptar el acuerdo no te concede automáticamente acceso a todos los documentos. La visualización sigue dependiendo de tu rol y de los permisos habilitados.

## ¿Qué significa «visible con solicitud»?

En la pestaña Documentación se distinguen:

- Documentos visibles: puedes consultarlos conforme al acceso habilitado.

- Documentos visibles con solicitud: debes pedir autorización antes de visualizarlos.

Según la guía funcional, cuando se aprueba una solicitud de acceso, el documento correspondiente pasa a ser visible para todos los inversores.

## Qué debes hacer

Revisa el nivel de acceso indicado para el documento. Si está sujeto a confidencialidad, acepta el acuerdo aplicable; si requiere solicitud, tramita el acceso y consulta el documento cuando se habilite.
