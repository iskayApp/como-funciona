# ¿Cómo se calcula automáticamente el monto solicitado?

## Respuesta breve

El monto solicitado se calcula automáticamente a partir de las unidades previstas y el precio unitario, considerando descuentos cuando existan.

## Explicación

El valor representa la expectativa de recaudación y ayuda a dimensionar la iniciativa. Su presencia no garantiza que las unidades se vendan o que el importe llegue a recaudarse.

## Qué debes hacer

Comprueba la coherencia entre unidades, precio, descuento y objetivo económico que se mostrará.

## Importante

No equipares el cálculo de una meta con una previsión asegurada de ingresos.
